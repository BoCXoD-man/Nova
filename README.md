# Nova — локальный голосовой AI-ассистент

**Nova — новая звезда, которая постепенно становится персональным ИИ-помощником пользователя.**

Nova — локальный голосовой AI-ассистент на Python. Проект объединяет распознавание речи, локальную языковую модель, систему команд, долговременную память и синтез речи.

Главная идея проекта — постепенно превратить обычный голосовой интерфейс в персонального ассистента, который понимает пользователя, помнит важную информацию о нём и использует этот контекст в дальнейшем общении.

---

# Архитектура

Основной принцип Nova — разделение ответственности между компонентами.

```text
                    ┌───────────────┐
                    │    Whisper    │
                    └───────┬───────┘
                            ↓
                          текст
                            ↓
                    ┌───────────────┐
                    │    Butler     │
                    │               │
                    │ command       │
                    │ parameters    │
                    │ memory        │
                    │ prompt        │
                    └───┬───────┬───┘
                        ↓       ↓
                    Command    Memory
                    Handler    Manager
                        ↓       ↓
                       API     SQLite
                       └────┬─────┘
                            ↓
                    ┌───────────────┐
                    │   Responder   │
                    └───────┬───────┘
                            ↓
                           TTS
                            ↓
                           Nova
```

Основной поток:

```text
Микрофон
   ↓
Whisper
   ↓
текст пользователя
   ↓
Context Manager
   ↓
Butler
   ↓
┌──────────────────────┐
│ command              │
│ parameters           │
│ memory               │
│ prompt               │
└──────────────────────┘
   ↓              ↓
Handler       Memory Manager
   ↓              ↓
 API            SQLite
   └───────┬──────┘
           ↓
       Responder
           ↓
          TTS
           ↓
       голос Nova
```

# Возможности

На текущем этапе Nova умеет:

* распознавать речь пользователя через Whisper;
* обрабатывать естественный язык с помощью LLM;
* определять намерение пользователя;
* формировать структурированные команды;
* выполнять команды через отдельные обработчики;
* работать с внешними API;
* сохранять информацию о пользователе;
* хранить долговременную память в SQLite;
* запоминать информацию о связанных с пользователем людях;
* хранить отношения между людьми;
* использовать сохранённую информацию при формировании ответа;
* формировать естественные ответы;
* озвучивать ответы через локальный TTS;
* работать с локальной LLM через `llama.cpp`;
* переключаться между локальной и облачной моделью через конфигурацию.

Проект находится в активной разработке.

# Компоненты

## Whisper

Whisper отвечает за распознавание речи пользователя.

```text
Голос → Whisper → текст
```

Распознавание выполняется локально.

---

## Butler

Butler отвечает за анализ пользовательского запроса и принятие решения о дальнейших действиях.

Он определяет:

* какую команду необходимо выполнить;
* какие параметры нужны команде;
* нужно ли изменить память;
* какой prompt необходимо использовать для формирования ответа.

Butler не выполняет команды самостоятельно.

Например:

```text
Пользователь:
Какая сейчас погода в Батуми?

        ↓

Butler

        ↓

command = weather
city = Батуми
```

После этого команда передаётся в соответствующий обработчик.

---

## Command Handler

`Command Handler` отвечает за выполнение команд, определённых Butler.

Например:

```text
Butler
  ↓
weather
  ↓
Command Handler
  ↓
Weather API
  ↓
результат
```

Такой подход позволяет добавлять новые команды и инструменты без изменения основной логики Nova.

---

## Memory Manager

`Memory Manager` отвечает за долговременную память Nova.

Он работает с SQLite и хранит информацию, которая должна сохраняться между запусками программы.

Память включает:

* профиль пользователя;
* факты о пользователе;
* связанных людей;
* отношения между людьми;
* факты о связанных людях.

Например:

```text
Андрей
├── жена ────────→ Карина
├── дочь ────────→ София
└── друг ────────→ Кирилл
```

А у связанных людей могут существовать собственные факты:

```text
София
└── любимая еда → бананы
```

---

## Context Manager

`Context Manager` собирает релевантную информацию из памяти и передаёт её дальше по цепочке обработки.

Nova не должна передавать языковой модели всю базу данных при каждом запросе.

Например:

```text
"А какую еду любит моя дочь?"

        ↓

Context Manager

        ↓

София
relation = дочь
favorite_food = бананы

        ↓

Butler / Responder

        ↓

"У твоей дочери Софии любимая еда — бананы."
```

Таким образом, память используется как источник контекста, а не как необработанный набор данных.

---

## Responder

`Responder` отвечает за формирование финального ответа пользователю.

Он получает:

* команду;
* параметры;
* результат выполнения команды;
* доступный контекст;
* релевантную информацию из памяти.

После этого формирует естественный ответ.

Responder не выполняет команды и не обращается к API напрямую.

---

## Text-to-Speech

После формирования ответа текст передаётся в локальную систему синтеза речи.

```text
Responder
   ↓
текст
   ↓
TTS
   ↓
голос Nova
```

# Память Nova

Память — одно из ключевых направлений проекта.

На текущем этапе реализована **долговременная память**.

```text
                  Memory System
                       │
          ┌────────────┼────────────┐
          ↓            ↓            ↓
       Profile      Relations      Facts
          │            │            │
          └────────────┼────────────┘
                       ↓
                Context Manager
                       ↓
                     Butler
```

## Что уже реализовано

* `User`
* `UserFact`
* `RelatedPerson`
* `Relation`
* `PersonFact`
* `MemoryManager`
* `ContextManager`
* сохранение профильных данных;
* сохранение фактов;
* сохранение связанных людей;
* сохранение отношений;
* сохранение фактов о связанных людях;
* поиск человека по имени;
* определение человека по родственному обращению;
* выбор релевантной информации из памяти.

Пример:

```text
"А где я живу?"

        ↓

Memory

        ↓

User.city = Батуми

        ↓

Nova

        ↓

"Ты живёшь в Батуми."
```

# Локальная LLM

Nova использует локальную языковую модель через `llama.cpp`.

Текущая модель:

```text
Qwen3-8B-Q4_K_M.gguf
```

Для ускорения инференса используется Vulkan и GPU.

## Тестовая конфигурация

```text
GPU:  AMD Radeon RX 590 8 GB
CPU:  AMD Ryzen 7 2700
RAM:  16 GB
OS:   Windows
```

Для работы локальной модели требуется сборка `llama.cpp` с поддержкой Vulkan.

---

# Запуск llama-server

Перейдите в каталог с `llama.cpp`:

```powershell
cd D:\AI
```

Запустите сервер:

```powershell
.\llama-server.exe `
    -m "D:\AI\models\Qwen3-8B-Q4_K_M.gguf" `
    -ngl 99 `
    -c 4096 `
    -t 12 `
    --port 8080 `
    --reasoning off
```

После запуска локальная модель будет доступна через OpenAI-compatible API:

```text
http://127.0.0.1:8080/v1
```

Nova обращается к локальной модели через этот API.

---

# Запуск Nova

После запуска локального LLM-сервера в отдельном окне PowerShell:

```powershell
cd D:\Work\Nova
```

Запустите приложение:

```powershell
python main.py
```

После запуска Nova переходит в режим ожидания голосовых команд.

Для остановки приложения:

```text
Ctrl+C
```

# Принципы проекта

## Разделение ответственности

Каждый компонент отвечает за свою область:

```text
Whisper          → распознавание речи
Butler           → принятие решений
Command Handler  → выполнение команд
Memory Manager   → долговременная память
Context Manager  → подбор контекста
Responder        → формирование ответа
TTS              → озвучивание
```

## Независимость компонентов

Основная логика Nova не должна зависеть от конкретной модели, API или сервиса.

## Структурированный обмен данными

Butler использует строгие структуры данных для передачи решений и параметров.

Это позволяет разделить:

```text
принятие решения
        ↓
выполнение действия
```

## Расширяемость

Новые возможности должны добавляться как отдельные инструменты или команды.

Например:

```text
weather
music
telegram
calendar
search
smart_home
```

без необходимости переписывать ядро Nova.
